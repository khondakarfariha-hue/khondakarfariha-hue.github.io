Undergraduate thesis developing a vision-based safety control system for collaborative robots (cobots) in industrial settings, using deep learning to keep human workers safe when sharing a workspace with robots.

**Approach:**
- Used YOLOv8n for real-time human detection
- Built and tested in a ROS2/Gazebo simulation environment
- Designed a three-zone safety classification system (Safe / Warning / Danger) based on human proximity to the robot
- Evaluated with mAP50, mAP50:95, Precision, Recall, and F1-Score

This work is currently being extended into a journal publication, with broader experimental scope including baseline comparisons against ISO/TS 15066 speed-and-separation-monitoring methods.
